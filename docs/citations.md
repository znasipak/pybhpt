# Citing `pybhpt`

If you make use of `pybhpt`, we request that you cite the Github package and accompanying papers using [CITATION.cff](https://github.com/znasipak/pybhpt/blob/main/CITATION.cff) or using the bib entries provided below.
```
@software{Nasipak_pybhpt_2026,
    author = {Nasipak, Zachary},
    license = {GPL-3.0},
    month = sep,
    title = {{pybhpt}},
    url = {https://github.com/znasipak/pybhpt},
    doi = {10.5281/zenodo.18317623},
    version = {v1.0.0},
    year = {2026}
}
@article{Nasipak:2025tby,
    author = "Nasipak, Zachary",
    title = "{Metric reconstruction and the Hamiltonian for eccentric, precessing binaries in the small-mass-ratio limit}",
    eprint = "2507.07746",
    archivePrefix = "arXiv",
    primaryClass = "gr-qc",
    doi = "10.1103/7zkx-vbg9",
    journal = "Phys. Rev. D",
    volume = "113",
    number = "12",
    pages = "124051",
    year = "2026"
}
@article{Nasipak:2022xjh,
    author = "Nasipak, Zachary",
    title = "{Adiabatic evolution due to the conservative scalar self-force during orbital resonances}",
    eprint = "2207.02224",
    archivePrefix = "arXiv",
    primaryClass = "gr-qc",
    doi = "10.1103/PhysRevD.106.064042",
    journal = "Phys. Rev. D",
    volume = "106",
    number = "6",

    year = "2022"
}
```
In particular, in addition to citing the numerical codebase itself, if you use the code for gravitational calculations, we request that you cite Ref. `\cite{Nasipak:2025tby}`, which was the first article to outline the algorithms and generic computations of gravitational perturbations within the `pybhpt` codebase. For scalar calculations, we request you cite either Ref. `\cite{Nasipak:2025tby}` or the work of earlier Ref. `\cite{Nasipak:2022xjh}`, which focused purely on the scalar field implementation.
